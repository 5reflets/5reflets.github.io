# 5reflets.github.io

Site d'accès à l'immeuble Vision 80, 5 terrasse des reflets, 92400 Courbevoie.

Repris depuis https://5reflets.wordpress.com/ et republié en HTML statique sur GitHub Pages.

## Publication

Repo prévu : organisation `5reflets`, repo `5reflets.github.io`.

Une fois l'organisation créée et le repo poussé, Pages est actif automatiquement (repo type organisation/user site). Site accessible sur `https://5reflets.github.io/`.

## Pages

1. `index.html` : accueil
2. `metro.html` : accès en métro
3. `voiture-paris.html` : voiture depuis Paris
4. `voiture-puteaux.html` : voiture depuis Puteaux
5. `voiture-nanterre.html` : voiture depuis Nanterre

Style commun : `style.css`. Images : `images/`.
